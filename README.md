# AI Health Prediction System

## Project Overview
A web-based Patient Health Record Management System built using Python Flask, SQLite, and Google Gemini AI.

## Technologies Used
- Python
- Flask
- SQLite
- HTML and CSS
- Google Gemini API

## Features
- Add and view patient records
- Update patient information
- Delete patient records
- Validate email addresses and dates of birth
- Validate numeric health values
- Generate AI-based health remarks using Gemini API

## Patient Information
- Full Name
- Date of Birth
- Email Address
- Glucose
- Haemoglobin
- Cholesterol
- AI Remarks

## Installation

1. Clone the repository.
2. Install dependencies:

   pip install -r requirements.txt

3. Create a `.env` file and add your Gemini API key:

   GEMINI_API_KEY=your_api_key

4. Run the application:

   python app.py

5. Open http://127.0.0.1:5000 in your browser.
